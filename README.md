# 🚗 Garbage Job - FiveM QBX/QBCore Script

A fully-featured garbage collection job script for FiveM servers running **QBX** or **QBCore**.

## Features

✅ **Multi-Route System** - 3 pre-configured routes (Downtown, Beach, Vinewood)  
✅ **Vehicle Management** - Auto-spawn and cleanup garbage truck  
✅ **Payment System** - Per-bin payment + route completion bonus  
✅ **GPS Navigation** - Blips for all collection points  
✅ **Animations** - Smooth collection animations with progress  
✅ **Easy Commands** - Simple chat commands to start/stop  
✅ **Fully Customizable** - All values in config.lua  
✅ **Export Functions** - Control via exports for integration
