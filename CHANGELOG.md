# Changelog

## [1.0.0] - 2026-05-18

### Added
- Initial release of Garbage Job script
- 3 pre-configured routes (Downtown, Beach, Vinewood)
- Vehicle spawning and management system
- Payment system with per-bin + route bonus
- GPS navigation with blips
- Collection animations and progress bars
- Customizable configuration
- Command-based job control
- Server-side payment processing
- Export functions for external integration
- Comprehensive documentation

### Features
- Multi-route support with customizable locations
- Automatic garbage truck management
- Interactive garbage collection mechanic
- Real-time progress tracking
- Payment logging to server console
- QBX/QBCore integration

### Scripts Included
- fxmanifest.lua - Resource manifest
- shared/config.lua - Configuration
- client/client.lua - Main client logic
- client/utils.lua - Utility functions
- server/server.lua - Payment processing
